Vanilla Web Architecture & CSS Engines

Modern UI design using standard web platform primitives. Learn semantic page structures, layout models, and clean styling without third-party CSS frameworks.

1. Semantic HTML5: Structure Over Division

Replace generic <div> tags with structural elements that provide context to assistive technologies, search crawlers, and future developers:

Navigation

<header> & <nav>

Wraps global page titles, navigation bars, and search inputs across the site.

Core Body

<main> & <article>

Declares primary document content and distinct, self-contained units (such as blog posts or project cards).

Grouping

<section> & <aside>

Divides content into themed areas with headings, or handles related side content.

Conclusion

<footer>

Contains copyright statements, terms of service, and secondary navigation links.

2. Mastering the CSS Box Model

Every HTML element rendered in a browser is enclosed in a four-layered rectangular container:

Content → Padding → Border → Margin

Always apply box-sizing: border-box; globally. Under the default content-box, adding padding or borders expands the element's rendered width. With border-box, dimensions remain predictable.

box-model-rule.css CSS Architecture 
/* Modern universally applied reset rule */
*, *::before, *::after {
    box-sizing: border-box;
    margin: 0;
    padding: 0;
}

/* Predictable component layout */
.card {
    width: 300px;        /* Total element width is locked at 300px */
    padding: 20px;      /* Padding sits inside the 300px boundary */
    border: 2px solid var(--border-color);
    margin: 16px;       /* Margin creates outside spacing */
}

3. Modern Layout: Flexbox vs. CSS Grid

Choose the layout algorithm best suited to your content's dimensional requirements:

Feature CSS Flexbox (1-Dimensional) CSS Grid (2-Dimensional)
Primary Axis Row or Column at a time Rows and Columns simultaneously
Best Used For Navigation menus, button groups, vertical centering Full page layouts, dashboard panels, image grids
Content vs. Grid Content-driven: Items size themselves Layout-driven: Items conform to track lines
responsive_grid.css Adaptive Layout without Media Queries 
/* Cards automatically wrap and balance their width */
.responsive-cards {
    display: grid;
    grid-template-columns: repeat(auto-fit, minmax(280px, 1fr));
    gap: 1.5rem;
}

/* Flexbox for aligning interior components */
.card-header {
    display: flex;
    justify-content: space-between;
    align-items: center;
}
