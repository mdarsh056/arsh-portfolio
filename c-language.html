2. Production Engine: Electricity Slab Billing

Calculates progressive tiered billing with meter rents and conditional surcharges. Demonstrates correct cumulative subtraction instead of flat rate multiplication.

electricity_billing.c C99 Standard 
#include <stdio.h>

int main(void) {
    float units, bill = 0.0f, surcharge = 0.0f, total;
    const float METER_RENT = 50.0f;

    printf("Enter total units consumed: ");
    if (scanf("%f", &units) != 1 || units < 0) {
        printf("Invalid unit input.\n");
        return 1;
    }

    /* Cumulative slab calculation */
    if (units <= 100) {
        bill = units * 3.00f;
    } else if (units <= 200) {
        bill = (100 * 3.00f) + ((units - 100) * 4.50f);
    } else if (units <= 300) {
        bill = (100 * 3.00f) + (100 * 4.50f) + ((units - 200) * 6.00f);
    } else {
        bill = (100 * 3.00f) + (100 * 4.50f) + (100 * 6.00f) + ((units - 300) * 8.00f);
    }

    /* Add 15% surcharge if consumption cost exceeds Rs. 1000 */
    if (bill > 1000.0f) {
        surcharge = bill * 0.15f;
    }

    total = bill + surcharge + METER_RENT;

    printf("\n--- UTILITY INVOICE ---\n");
    printf("Base Consumption Bill: Rs. %.2f\n", bill);
    printf("Surcharge:             Rs. %.2f\n", surcharge);
    printf("Meter Rent:            Rs. %.2f\n", METER_RENT);
    printf("Total Payable:         Rs. %.2f\n", total);

    return 0;
}

Dry-Run Analysis (Input: units = 250)

1. units > 200 and units <= 300 triggers Slab 3.

2. Slab 1 cost: $100 \times 3.00 = 300.00$.

3. Slab 2 cost: $100 \times 4.50 = 450.00$.

4. Slab 3 remainder: $(250 - 200) \times 6.00 = 50 \times 6.00 = 300.00$.

5. Base Bill: $300 + 450 + 300 = 1050.00$.

6. Since $1050.00 > 1000.00$, Surcharge applies: $1050 \times 0.15 = 157.50$.

7. Final Total: $1050.00 + 157.50 + 50.00 \text{ (Meter Rent)} = \mathbf{1257.50}$.

3. Algorithmic Kernels: Reversal & Factorial

Fundamental mathematical routines tested in academic computer science papers.

math_kernels.c Iteration & Logic 
#include <stdio.h>

/* Reverses any 32-bit signed integer safely */
long long reverse_integer(int n) {
    long long rev = 0;
    int temp = n;
    while (temp != 0) {
        int remainder = temp % 10;
        rev = rev * 10 + remainder;
        temp /= 10;
    }
    return rev;
}

/* Computes Factorial iteratively to avoid stack overflow */
unsigned long long factorial(int n) {
    if (n < 0) return 0; // Undefined
    unsigned long long fact = 1;
    for (int i = 1; i <= n; ++i) {
        fact *= i;
    }
    return fact;
}

4. Memory Management: Pointers & Dynamic Allocation

In C, heap memory is managed manually. Every allocation made via malloc() or calloc() must be paired with an explicit free() call to prevent memory leaks.

dma_lifecycle.c Heap Memory 
#include <stdio.h>
#include <stdlib.h>

int main(void) {
    int n = 5;
    int *arr = (int *)malloc(n * sizeof(int));

    if (arr == NULL) {
        printf("Heap allocation failed!\n");
        return 1;
    }

    /* Pointer arithmetic assignment */
    for (int i = 0; i < n; i++) {
        *(arr + i) = (i + 1) * 10;
    }

    /* Deallocation and pointer safety */
    free(arr);
    arr = NULL; // Prevents dangling pointer reference

    return 0;
}
